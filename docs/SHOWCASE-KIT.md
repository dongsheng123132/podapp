# PodApp 展示与参赛材料

## 一句话

泊舟 PodApp 是桌面 AI 小程序运行舱：AI 负责生成，PodApp 用可验证动作把结果真正做完。

## 90 秒演示

| 时间 | 画面 | 要证明的事 |
|---|---|---|
| 0-10 秒 | 小船吸附 Codex；拖到顶部后自动磁吸 | 是真实桌面工具，不是网页概念稿 |
| 10-30 秒 | 打开内置 Pod，输入或拖入一个真实文件 | 用户路径短 |
| 30-50 秒 | 预览、确认、执行并拿到产物 | AI 输出被确定性动作完成 |
| 50-70 秒 | 用同一个 Action ID 无头执行 | GUI 与 AI 没有两份业务逻辑 |
| 70-85 秒 | 切换橘猫皮肤，展示 JSON 导入 | 社区能低门槛扩展 |
| 85-90 秒 | 展示权限清单与开源仓库 | 边界可检查、结果可复现 |

## 评委测试

```powershell
git clone https://github.com/dongsheng123132/podapp.git
cd podapp
cargo test --workspace

cd apps/podapp-dock
pnpm install --frozen-lockfile
pnpm build

cd src-tauri
cargo run
```

验收动作：

1. 拖动收起态把手到四边和四角，窗口保持可见并显示自由漂浮状态。
2. 重启后位置不变；点击重新吸附后跟随 Codex。
3. 切换“橘猫”，导入一份符合规范的皮肤 JSON。
4. 打开备忘贴 Pod，分别从 GUI 和无头入口执行同一个动作。
5. 检查未授权文件、网络和子进程访问被拒绝。

## 差异点

- 动作只实现一次，GUI、AI、CLI 和远端调用共享 Action ID。
- 权限检查在动作核心之下统一执行，不依赖某个按钮是否可见。
- Pod 是可安装动作包，不是只在聊天里展示的代码片段。
- 皮肤是安全声明，不执行第三方前端代码。
- 吸附、自由漂浮、边缘磁吸和多屏坐标由纯几何测试覆盖。
