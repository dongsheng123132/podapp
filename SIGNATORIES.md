# Signatories of the AI GUI Manifesto

[Read the manifesto](./MANIFESTO.md) · [阅读中文版](./MANIFESTO.zh-CN.md)

Signing means supporting the direction of the AI GUI Manifesto: explicit intent, visible state,
recoverable action, bounded authority, open contracts, and meaningful human control.

It does not require agreement with every current PodApp implementation decision, and it does not
create a legal, commercial, or organizational relationship with PodApp.

## How to sign

Open a pull request that adds one row to the appropriate table. Use a name you are comfortable
publishing permanently. A personal site or public profile is optional; do not add private contact
information.

For a project or organization, the pull request should come from an owner or authorized
representative. Add only your own signature unless another person has explicitly asked you to
submit theirs.

Signatures may be removed on request or when they are fraudulent, misleading, abusive, or used to
imply an endorsement beyond this manifesto.
